# Chest Lock

Minecraft Paper 向けのチェストロックプラグインです。チェストを「公共用チェスト」「個人用チェスト」に設定し、破壊や使用を制限できます。

## 機能

### 1. 公共用チェスト
- **鉄チェーン**を持って通常チェストを **シフト + 右クリック**：公共用チェストに設定（チェーンを 1 つ消費）
- 一度設定すると解除不可
- 破壊は設定者（所有者）のみ可能
- 誰でも自由に使用可能

### 2. 個人用チェスト
- **銅チェーン**（錆び・ワックス有無を問わない）を持って通常チェストを **シフト + 右クリック**：個人用チェストに設定（チェーンを 1 つ消費）
- 設定したプレイヤーが所有者になる
- 所有者と共有ユーザーのみ使用可能

### 3. ユーザー共有
- **銅チェーン**を持って自分の個人用チェストを **右クリック**：ユーザー名の入力画面（金床）が開く
- MCID を入力すると、そのプレイヤーに使用権限を付与
- 共有ユーザーの追加は所有者のみ可能
- 入力された MCID は Mojang API で存在確認されます。確認できなかった場合は「(MCID)を追加しますか？」の確認画面（はい / いいえ）が表示されます

### 4. 個人用設定の解除
- **斧**（素材不問）を持って個人用チェストを **右クリック**：個人用設定を解除
- 解除できるのは所有者のみ。解除すると通常のチェストになり、誰でも使用できます
- 公共用チェストは解除できません（斧で右クリックしても通常どおり開くだけです）

### 5. OP による設定変更
- **OP 権限があり、かつクリエイティブモード**のプレイヤーは設定済みチェストの設定を変更できます
  - チェーンで設定済みチェストに設定し直す（公共 ⇄ 個人の変更・所有者の変更）
  - 斧で公共用チェスト・他人の個人用チェストを解除する

### ラージチェストへの増結
- 設定済みチェストにチェストを追加してラージチェストにすると、設定は自動的に引き継がれます
- **増結できるのは所有者のみ**です。共有ユーザー・その他のプレイヤーは増結できません

### ホッパー・ホッパー付きトロッコ
- **個人用チェスト**：所有者と共有ユーザーのみホッパー／ホッパー付きトロッコの設置とアイテム搬送ができます（それ以外のプレイヤーのホッパーからの搬出・搬入はできません）
- **公共用チェスト**：ホッパーの使用は自由です
- ホッパーは誰が設置したかを記録して判定するため、プラグイン導入前に設置されたホッパーは所有者のものとして扱われません。必要に応じて設置し直してください

### 破壊と警告
- 所有者が設定済みチェストを破壊すると設定が解除されます（「ロック/共有化されたチェストを破壊したため、設定が解除されました。」と表示）

### ペナルティ（警告と PvP）
個人用チェストを勝手に開けようとした場合・設定済みチェストを破壊しようとした場合（ロック・公共を問わない）に、試行回数に応じて段階的にエスカレーションします。ロック解除を試みた場合は警告の対象外です。試行カウントは 10 分間の無操作でリセットされます（config の `penalty` で調整可能）。

| 試行回数 | 内容 |
|---|---|
| 2 回目 | 本人に「あと1回で所有者と使用可能な人に警告が行きます」と表示 |
| 3 回目 | 所有者・共有ユーザーに警告。本人にも「警告が行きました」と表示 |
| 4 回目 | 本人に「あと1回でPvPが有効になります」と表示 |
| 5 回目 | **5 分間、その人に対して PvP が有効になります**。所有者・共有ユーザーに通知（破壊試行の場合は半径 15m のプレイヤーにも通知） |

- **PvP ペナルティ中**：所有者・共有ユーザーからのみ攻撃できます（PvP が無効なワールド・サーバーでも同様）。対象者は誰にも攻撃できず（抵抗不可）、第三者も対象者を攻撃できません
- ペナルティ中はワールドの PvP 設定を一瞬だけ有効化して直後に戻す方式のため、Multiverse 等のワールド管理プラグインや LuckPerms と競合しません
- **アラートのクールダウン**：警告が鳴った後、そのプレイヤーの新しいエスカレーションは **5 分間**開始されません。公共チェストの破壊試行で鳴った場合は **10 分間**です（警告のスパム防止）
- 各時間（試行カウントのリセット・クールダウン・PvP 継続時間）は `config.yml` の `penalty` で調整できます

### 効果音
チャットメッセージが表示される場面には基本的に効果音が鳴ります。聞こえるのは行動した本人（警告は警告の受け取り側）のみです。`config.yml` で変更できます。

| シチュエーション | 音 |
|---|---|
| チャット表示時（基本音） | UI ボタンクリック音 |
| ロック時 | 金床の使用音 |
| 公共化時 | レベルアップ音 |
| 解除時 | 金床破壊音 |
| 破壊時（所有者による） | 金床破壊音 |
| 増築時 | 基本音 |
| 警告時 | 経験値オーブ取得音 |
| 破壊失敗時 | 金床設置音 |
| 使用失敗時 | 金床設置音 |
| 解除失敗時 | 金床設置音 |

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/chestlock version` | プラグインのバージョンを表示 | 誰でも実行可 |
| `/chestlock list` | ロック・公共に設定されたチェストの座標と所有者を一覧表示 | 誰でも実行可 |
| `/chestlock unlock <x> <y> <z>` | 指定座標のチェストを通常のチェストに戻す | OP 必要 |
| `/chestlock status <x> <y> <z>` | 指定座標のチェストの状態を未設定 / ロック / 公共で表示 | OP 必要 |

- 座標コマンドはデフォルトで実行者のいるワールドが対象です。コンソール実行時や別のワールドを指定する場合は末尾にワールド名を追加できます（例: `/chestlock status 0 64 0 world_nether`）。
- ラージチェストの場合は両方の半分がまとめて解除されます。

### 権限ノード

| ノード | デフォルト |
|---|---|
| `chestlock.command.version` | 全員 |
| `chestlock.command.list` | 全員 |
| `chestlock.command.unlock` | OP |
| `chestlock.command.status` | OP |

## 導入方法

1. [Releases](../../releases) から最新の jar をダウンロード
2. サーバーの `plugins` フォルダに入れる
3. サーバーを再起動

## ビルド方法

```bash
./gradlew build
```

`build/libs/` に配布用の jar と、ソースコードを同梱した jar が生成されます。

## 設定

`plugins/ChestLock/config.yml` でチャットメッセージと効果音を変更できます。`{player}` `{owner}` `{world}` `{x}` `{y}` `{z}` `{status}` `{version}` がプレースホルダとして使えます。

## データ保存

チェストの設定は `plugins/ChestLock/data.yml` に保存されます。バックアップする場合はこのファイルをコピーしてください。
